📚 How It Works — BCA Demonstration & Viva Voce Guide ▼

1. What is a Latent Diffusion Model (LDM)?

Standard image generation operating directly on raw RGB pixels (\(1024 \times 1024 \times 3\)) requires massive GPU compute. Latent Diffusion Models solve this by utilizing a Variational Autoencoder (VAE) to compress the image into an 8x smaller latent tensor space (\(128 \times 128 \times 4\)), where diffusion and denoising happen efficiently.

2. Step-by-Step Generation Pipeline:

  1. Text Encoding (CLIP / T5): The user's prompt is tokenized and transformed into continuous vector embeddings that represent semantic meanings.
  2. Latent Noise Injection: A random tensor filled with Gaussian noise is generated in latent space.
  3. Cross-Attention Denoising (U-Net / DiT): Across multiple discrete time steps (e.g., 30 steps), the neural network iteratively estimates and subtracts noise, conditioned on the text embeddings.
  4. VAE Decoding: The final cleaned latent representation is decoded into full-resolution RGB pixels and saved as a PNG using Pillow.

3. Why Docker Containerization?

Docker isolates PyTorch, CUDA libraries, Python interpreters, and dependencies inside a reproducible container. This prevents OS version conflicts and ensures the exact same model pipeline executes smoothly on any development laptop, lab PC, or production cloud server.
